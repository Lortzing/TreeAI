## Open engineering item (not silently dropped)

- **ToolPolicy real-path integration (issue #5 P0)**: the offline portion has landed. `PiRuntimeConfig.toolPolicy` (packages/runtime-pi) injects a policy evaluator — the real `ToolPolicyEngine` satisfies the structural seam — and the runtime installs a request-time gate on every session it creates or restores (real port: public-mutable `Agent.beforeToolCall`, chained ahead of the AgentSession extension hook; issue #5's "单纯合成 tool event 不算" no longer applies: decisions come off the actual execution path). Allow → the tool executes; deny / require-approval → no execution, a `tool.decision` event with provenance (tool name, outcome, category, risk, fixed-template reason, ruleId — never parameters/paths/commands), and the run converges failed with code `policy-denied` (fail-closed semantics, chosen and documented in the runtime-pi README since none was defined). Studio now surfaces this: `tool-activity` SSE gains a `denied` phase with decision provenance, journal `tool.decision` rows render with rule provenance, and `/diagnostics` policyDecisions honestly reports observed decisions (still `observed:false` under the default empty-allowlist wiring). Verified offline three ways: runtime-pi unit tests (fake port, structural evaluator), the real-SDK offline battery (sandboxed child, unroutable provider, scripted `Agent.streamFunction` driving the real agent loop and real built-in read/write tools against the real ToolPolicyEngine — allow executes, overreach never executes, grant flow, require-approval fail-closed), and the runtime-smoke scenario (fake Pi port + real engine, journal/DB/projection consistency, now 9 runs / 5 request-path decisions). What remains owner-side: a real-Pi run through the Studio product path using the landed CLI wiring (`--pi-tools` / `--policy-read-roots`, read roots defaulting to the data-dir workspace; the default wiring still enables zero tools by design) plus a UI-level recording at the final SHA, and any decision on relaxing fail-closed run semantics.
