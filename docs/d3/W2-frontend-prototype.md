## 3. 动效分镜（状态转场清单）

总则：每个动效必须有 `prefers-reduced-motion` 等价物；转场克制（数量少、
时长短、无循环装饰动画）；状态绝不只靠动效表达（同时有颜色 / 文案 / 图标）。

| # | 动效 | 触发 | 常规形态 | reduced-motion 等价 | 状态 |
| --- | --- | --- | --- | --- | --- |
| M1 | 支线面板进入 | 打开支线 | 侧滑 + 淡入，150–200ms，ease-out | 仅透明度 0→1（或直接出现，无位移） | 未开始 |
| M2 | 支线面板退出 | 关闭支线 | 对称退出 ~150ms | 仅透明度 1→0 | 未开始 |
| M3 | Return 卡插入 | Return `confirmed` | 高度展开 + 淡入，≤200ms | 即时插入 | 未开始 |
| M4 | Return 卡状态变化 | `confirmed` → `delivered` | 徽标颜色 / 文案切换 ~100ms | 即时切换 | 未开始 |
| M5 | Run 状态指示变化 | idle → streaming → aborting / 终态 | 颜色 + 文案过渡 ~100ms；streaming 用静态指示（不旋转） | 即时切换 | 未开始（旧形态即时切换，待源设计对照） |
| M6 | 锚点高亮强调 | 揭示到位 | 背景脉冲 1–2 次后保持静态高亮 | 直接静态高亮 | 未开始（旧形态为静态高亮） |
| M7 | 滚动定位 | 揭示 / 切分支 | 平滑滚动 | 直接跳转（`auto`） | 未开始（旧形态固定 `smooth`） |

| 项 | 现状 | 验证步骤 | 状态 |
