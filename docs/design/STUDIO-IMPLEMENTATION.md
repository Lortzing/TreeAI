# Studio 设计落地 · 2026-10-15

将负责人认可的 `treeai-studio/` 交互稿应用到 `apps/studio/public/`，沿用现有原生前端、API 与 runtime，不增加依赖或数据库迁移。

## 实际变化

- 暖纸色阅读、松绿森林侧栏、苔绿 Return 卡、系统中文衬线标题。没有外部字体请求，离线可用。
- 桌面 238px 侧栏、中央稳定阅读区、340–390px 右侧探索列；中等窗口使用支线覆盖层；手机使用导航抽屉与全幅支线。
- 标题来自已保存的主线首问。树列表复用现有只读导航摘要，未读到标题时显示原 ID；树按钮使用稳定的 `data-tree-id`。
- 材料进入中央阅读区，保留原来的材料解析、版本、PDF 文字层、规范文本与选区映射。覆盖主线而不移除它的节点；切回时保留主线位置和未提交输入。
- 搜索与深度导航使用原生 disclosure 按需展开。搜索快捷入口及 ⌘/Ctrl+K 聚焦原表单，不清除检索词或筛选；唯一材料可从中央阅读入口直接打开，多份材料进入侧栏选择。
- 主运行状态保持可见，详情、策略和会话引用放入原生运行详情弹层；中止操作始终就近可用。来源抽屉、故障与会话缺失提示继续保留。
- 右侧支线保留固定出处/返回动作、连续追问和持久 Return 草稿。回程仍是编辑后显式确认，保存、采用尝试、首次成功采用的状态不合并。
- 使用既有 enter/exit、来源高亮、Return 插入动画及减少动态效果规则。正文不做逐条入场或循环装饰动画，避免干扰流式阅读和选区。

## 启动

```bash
npm run start --workspace @treeai/studio
```

默认地址 `http://127.0.0.1:8787`。本次检查实例使用 `8788`，原型仍在 `8790`。检查实例与用户原有数据隔离。完整字体、颜色与布局 token 位于 `public/style.css`；界面结构位于 `public/index.html`；只读摘要和入口行为位于 `public/app.js`。
