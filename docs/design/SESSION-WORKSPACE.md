# Session 工作区

2026-10-19，按最新确认收敛为两个视图：对话与 Session 关系。对话页就是轮次页，取消整个 Session 长列表及独立只读卡片页。

## 对话

每次只显示一个 Episode 的真实消息与关联 Return，同轮可以包含多条用户、模型消息和多次执行。直接使用已有正文、输入框、选词探索、解释、来源和收获操作，不复制一份只读内容。

底部上一轮／下一轮按钮、非编辑区域的左右方向键及手机横向滑动用于翻页。首尾按钮禁用。轮次内部可纵向阅读，滚动位置按树、Session、轮次隔离。发送继续当前 Session，提交完成后跟随最新轮次；来源跳转自动定位包含锚点的轮次。

页面删除介绍性口号及英文装饰标题，仅保留内容、操作、必要状态和错误说明。暖白纸页、浅绿色用户消息及背层纸页表现同一 Session 的轮次组；翻页使用 280ms 位移和淡入，遵守减少动态效果设置。

## Session 关系

每组卡片对应产品层 Branch，连线来自真实 parentBranchId；点击直接进入该 Session 的轮次对话。切换视图保留未发送文本和收获草稿。图内滚动、缩放、重置，最多渲染 120 组，其余通过深度导航访问。

产品 Session 不按物理 Pi 文件分组。Episode 缺失的旧数据按 Run、Turn 身份保守回退；Return 不制造对话轮次。没有对话的 Session 显示 00 / 00，仍可输入。

## 验证

Studio 测试 415/415 通过，覆盖多消息多执行分组、翻页边界、历史来源定位、草稿及现有流式与材料操作；全工作区类型检查通过。浏览器检查桌面 1440×1000、手机 390×844 及 320×640。
