# TreeAI Studio · 生长中的思考

本轮为独立交互设计稿，不替换正式 Studio。以 `docs/d4/D4-project-v1.md` 的材料学习闭环和 `docs/d3/W2-frontend-prototype.md` 的主线／局部支线语义为基础。示例数据只用于呈现布局、状态与操作，不连接模型、不写数据库，刷新即恢复。

## 核心设计

**让每一次好奇，都有归处。** 森林是问题的集合；主干承载持续思考；支线允许局部深入；Return 是用户确认过的理解。视觉和动画围绕这四层关系展开。

阅读面采用暖纸色 `#FBFAF7`，松绿 `#34583E` 表达主线和主要操作，浅苔绿用于出处与收获。中文衬线标题带来书页感，正文使用系统无衬线字体。外部字体未加载时自动回退。正式本地发行时应把字体随安装包提供，或采用系统字体。

桌面左栏 238px；右侧探索列 340px；中间阅读区保持稳定。小于 1180px 时探索变为覆盖层，不挤动主线；小于 720px 时导航进入抽屉、探索覆盖工作区。材料和主线是同一棵树的两种阅读面。来源和返回动作固定在探索面板顶部。

## 动画规范

| 动作 | 视觉 | 时长 | 意义 |
| --- | --- | --- | --- |
| 开枝 | 支线沿横向 28px 展开，同时淡入 | 420ms | 从局部出处进入探索 |
| 切换阅读面 | 页签下划线伸展 | 250ms | 标明正在阅读的内容 |
| 揭示出处 | 原文短暂浅绿高亮 | 1300ms | 让用户看见探索起点 |
| 确认回程 | 收获卡向上 12px 落入主线 | 420ms | 把支线发现汇聚为理解 |
| 确认对话框 | 向上 10px，缩放 .98 → 1 | 250ms | 聚焦确认动作 |

统一曲线 `cubic-bezier(.22,1,.36,1)`。无自动循环动画；正文和流式文本在正式实现中保持稳定。系统启用减少动态效果时，动画、过渡、平滑滚动均即时化。

## 可体验路径

1. 点击正文「反馈回路」或「沿着反馈回路深入」，展开右侧支线。
2. 点击「回到出处」，收起支线并高亮起点；也可直接返回，不提交 Return。
3. 点击「把收获带回主线」，修改内容后显式确认；收获卡保留探索入口。
4. 切换「阅读材料」，从示例原文展开探索；来源展示材料标题、v1 与段落。
5. 查找示例条目、种下示例树、输入主线思考或支线追问。

设计稿仅展示最后一张 Return。对话来源 Return 位于原回答之后；材料来源 Return 位于主线末尾，不伪造对话锚点。正式版本按确认时间放置材料 Return，保留材料版本、摘录、时间和采用状态。

树切换演示只改变标题，沿用通用示例正文，并通过提示明确说明。输入只展示用户文本，不生成模型回答。导航、搜索、新树与收获均为当前页面内存状态。

## 预览

在仓库根目录运行：

```bash
python3 -m http.server 8790 --bind 127.0.0.1 --directory docs/design/treeai-studio
```

浏览器访问 `http://127.0.0.1:8790`，也可直接打开 `index.html`。

## 正式前端落地边界

沿用现有 API 与原生前端，优先改造视觉 token、阅读布局与局部支线。保留服务端来源事实、版本定位、草稿、幂等提交、失败／断流／缺失会话提示、键盘焦点还原与阅读位置。此设计稿不宣称覆盖正式产品所有功能与状态，也不代表产品验收完成。
