# Studio 体验重设计与下一阶段计划

日期：2026-10-28。负责人要求：前端优先改善美观、简洁和易用性；真人试用验收暂缓，不作为本阶段推进的前置条件。历史验收门槛保留原状态，本计划不把暂缓记为通过。

## 本轮实现：让阅读和思考成为视觉中心

- 以浅暖白阅读面、低对比侧栏、石墨文字和单一松绿强调色统一工作台。减少主阅读区的嵌套边框，限定正文行宽，让输入框成为稳定的主要操作区。
- 收窄侧栏，降低来源、设置、视图切换的视觉权重。运行、错误和恢复入口继续可见；关系图、搜索、阅读材料继续沿用现有功能。
- 首次进入解释“提问 → 展开支线 → 带回收获”，提供一个明确开始入口。
- 空树提供“理解概念 / 比较选择 / 梳理想法”三个问题起点。点击只填入空输入框并聚焦；用户已有内容不被覆盖，也不会自动请求模型。
- 无标题树以“新的思考”呈现；真实 ID 保留在列表提示信息及身份路径中。已有首问仍用于生成可读标题。
- 支线沿用当前独立工作面，统一来源上下文、输入框与收获区域的排版。Return 保存与导航顺序、来源身份、会话恢复和预算状态机没有改动。

本轮是实际产品代码的体验版本，不是已获用户认可的最终设计。真实模型质量与真人评价不从自动测试推断。

## 第二轮：暖白与导航减负

基线已确认就是 PR #29 的合并提交 `35ae4a012fd6beea0b66b9bb773dbe858dfedc45`；第一轮本地修改没有另行合并，也不冒充主线已包含本页的新设计。

- 画布 `#faf9f6`、内容面 `#fffefa`、侧栏 `#f0efea`，保持偏白，同时避免冷灰和纯白的大面积对比。
- 左侧只保留新建、搜索、历史列表、底部设置。历史行去掉重复日期与装饰点，日期和身份仍可通过提示信息查看。
- 当前路径、材料与扩展导航移入右上角“资料与路径”二级面板。原来的数据和控件继续复用，选中材料或路径后收起面板；Escape 关闭面板并还原焦点。阅读材料图标提供直达入口。
- 来源记录、运行详情和阅读材料改为图标，附带可访问名称与悬停说明。新建、搜索、设置这些全局入口保留短文字，避免陌生图标增加寻找成本。
- 设置改为独立全页，返回按钮与原生 dialog 焦点管理保留。Escape 不再同时关闭底层的工作区内容。
- 关闭阅读器或支线时，先展开原触发按钮所属的二级面板，再恢复焦点。窄窗历史抽屉与工具面板互斥，防止互相盖住。

## 下一阶段顺序

### P0：先把一条完整思考流程打磨顺畅（建议 2–3 个工作日）

目标：从新建到首问、选文深入、确认收获、重新找到收获，操作位置和状态始终清楚。

1. 统一主线、支线、材料、来源、错误与恢复提示的中文用语；把内部术语、ID、session 诊断留在详情，保留准确错误原因与可执行恢复动作。
2. 在本轮已收敛的导航结构上，继续完善多棵未命名树的区分方式和重命名；观察图标入口的可发现性，按需要补短标签。
3. 改善收获确认体验：清楚展示保存结果、是否已被主线采用、导航失败后的重试路径；编辑内容与焦点不因异步刷新丢失。

完成标准：桌面与 390px 窄窗覆盖新建、发送、选文建枝、收获保存、恢复和切树；键盘操作可完成主要流程；无重叠、横向溢出、不可见错误和草稿覆盖。复用既有 Return/选区回归，必要时增加行为测试。

### P1：阅读与整理形成闭环（建议 3–4 个工作日）

目标：读长材料和回看复杂思考时仍容易定位。

1. 统一 PDF / Markdown 阅读工具栏、导入进度、版本提示、选文动作和返回位置；材料与对话之间的切换保留阅读位置。
2. 整理关系图的信息密度：突出当前路径与来源，支线标签可读，长标题有完整查看方式；保留大树虚拟化与分页边界。
3. 搜索结果以可识别标题、内容摘录、来源类型和位置呈现；区分空结果、检索失败、旧版本和会话不可续聊。

完成标准：长文、旧版本、大树和多轮历史的真实浏览器自动回归通过；搜索到的保存事实可准确跳转；会话不可用不遮蔽已保存内容。

### P2：稳定性与交付质量（建议 2–3 个工作日）

目标：让体验版本可以稳定安装、启动和持续使用。

1. 合并已被替代的视觉规则，明确样式的唯一归属，避免继续叠加覆盖；保持静态资源白名单、安装包包含项与测试发现路径一致。
2. 对长回答、流式输出、连续切树和大量路径做性能与故障检查；保持用户主动阅读位置，不强制滚回底部。
3. 记录最终代码版本的类型、完整测试、浏览器与打包结果。真实模型验证单独记录；只有实际执行的检查才计通过。

完成标准：固定 Node/npm 和锁文件；完整自动检查通过；安装包启动、重启、数据保存与恢复的工程检查可重现。

上述时间是工作量估计，不是排期承诺。若 P0 暴露流程阻碍，优先修复后再进入 P1。当前不扩展协作、云同步、账号系统或新的框架。
