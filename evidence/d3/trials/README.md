# evidence/d3/trials/ — 独立试用记录（A6 / P1）

- 定位：issue #2 P1——组织 **3–5 人独立**完成**同一真实任务**，逐人记录
  卡点 / 耗时；修复阻断问题后**复测**。A6 验收（非开发者试用）与本目录
  记录同源。
- 所有试用必须在**同一构建**（同 commit SHA、同目标机器环境）上进行；
  试用之间不得更换构建（修复阻断问题后的复测除外，且复测须绑定新 SHA
  并注明对应修复）。

## 结构

```text
evidence/d3/trials/
├── task-script.md          # 统一真实任务脚本（固定文本；脚本变更随新 SHA
│                           #   追加新版本，不改写旧版）
└── <trial-id>/
    ├── person-01.md        # 每人一份（复制 templates/run-record.md）
    ├── person-02.md
    └── retest-<UTC-id>.md  # 修复阻断问题后的复测（新记录，不改写原始记录）
```

## 每人记录必含

- 任务（同一脚本，注明脚本版本 / SHA）；
- 开始 / 结束时间与关键步骤耗时（逐屏或逐任务段）；
- 卡点逐条：现象、当时操作、是否阻断任务完成；
- 是否完成任务（如实：完成 / 部分完成 / 未完成）；
- 修复对应的 commit SHA 与复测结论（修复后追加复测记录）。

## 规则

1. **参与者匿名**：只编号（person-01…），不记录姓名等可识别个人信息。
2. 只追加；绑定 SHA；脱敏 ID；写盘前后 secret scan——区域规则见
   `evidence/d3/README.md`。
3. 试用中观察到的缺陷如实记录为卡点，**不改写为通过**；阻断问题的修复
   以新记录 + 新 SHA 追加，原始试用记录保持原样。
4. 不声明门禁结论（A6 是否满足由负责人签署判定）。
